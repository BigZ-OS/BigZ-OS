## Português

### O que é
O BigZ OS é um conjunto **open source** de scripts e ferramentas que transforma a **ISO oficial do Windows que você baixou** em uma de três edições, mais uma *toolbox* para usar depois de instalar.

| Edição | Para quem | Foco |
|---|---|---|
| **DEV** | Desenvolvedores | Ferramentas de dev, toolbox completa, shell e Explorer personalizados, bom desempenho |
| **Balanced** | Uso geral | Seguro, estável, personalizável |
| **Full Performance** | Gamers / desempenho extremo | Remove o que pesa; toolbox só de desempenho |

### ⚠️ Avisos importantes
- **Não distribuímos o Windows.** Não oferecemos ISOs, imagens nem binários da Microsoft. Você usa **sua** ISO oficial e **sua** licença do Windows.
- **Sem ativadores, cracks ou bypass de licença.** Nunca.
- **Não somos afiliados, patrocinados nem endossados pela Microsoft.** "Windows" e "Microsoft" são marcas de seus respectivos titulares.
- **Modifica o sistema.** Use primeiro em **máquina virtual**, faça backup e leia a documentação de cada ajuste. Sem garantia (ver licença).

### Princípios
1. **Código aberto e auditável** — sem binários opacos.
2. **Cada ajuste é documentado** e, sempre que possível, **reversível**.
3. **Releases com checksums** [e assinatura — a definir].
4. **Gratuito.** Sempre.

## English

### What it is
BigZ OS is an **open-source** set of scripts and tools that turns **the official Windows ISO you downloaded yourself** into one of three editions, plus a post-install *toolbox*.

| Edition | Audience | Focus |
|---|---|---|
| **DEV** | Developers | Dev tools, full toolbox, customized shell/Explorer, good performance |
| **Balanced** | General use | Secure, stable, customizable |
| **Full Performance** | Gamers / max performance | Strips what's heavy; performance-only toolbox |

### ⚠️ Important notices
- **We do not distribute Windows.** No ISOs, images or Microsoft binaries are provided. You use **your own** official ISO and **your own** Windows license.
- **No activators, cracks or license bypasses.** Ever.
- **Not affiliated with, sponsored by, or endorsed by Microsoft.** "Windows" and "Microsoft" are trademarks of their respective owners.
- **It modifies your system.** Try it in a **virtual machine** first, back up your data, and read each tweak's docs. No warranty (see license).

### Principles
Open and auditable code (no opaque binaries) · every tweak documented and reversible where possible · releases with checksums · free, always.
