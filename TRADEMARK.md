# Política de Marca — BigZ OS

> **Aprovada pelo mantenedor; pendente de revisão jurídica.** Não é parecer jurídico.
> Aviso: não registramos a marca. Esta política descreve como o projeto *pretende* ser tratado; não cria direitos de registro.

## 1. O que isto cobre
O nome **"BigZ OS"**, o logotipo e a identidade visual oficiais ficam **fora** das licenças do projeto (GPL-3.0-or-later para o código, CC BY-SA 4.0 para os assets): essas licenças dão direito de usar, modificar e redistribuir, mas **não** dão direito de usar o nome e o logo como se fossem a versão oficial.

## 2. Pode, sem pedir permissão
- Dizer que seu texto, vídeo, tutorial ou comparação **usa, é baseado em ou é compatível com** o BigZ OS (uso referencial e honesto).
- Redistribuir o código sob a GPL, **mantendo os avisos de copyright e a atribuição** ("Baseado no BigZ OS — https://github.com/BigZ-OS/BigZ-OS").
- Fazer um fork e publicá-lo **com outro nome** e outro logotipo.
- Reproduzir o logo ao falar do projeto (resenhas, notícias, links de download oficiais).

## 3. Não pode
- Chamar uma versão modificada de "BigZ OS" ou usar o logo oficial de modo que pareça oficial, endossada ou mantida pela equipe.
- Distribuir builds modificadas **com o nome oficial**, especialmente com **código não publicado**, binários opacos, telemetria oculta ou ativadores.
- Usar nome ou logo para sugerir **afiliação com a Microsoft**, ou usar "Windows" no nome do seu produto/domínio.
- Registrar domínio, perfil, loja ou marca que imite "BigZ OS" para enganar usuários.

## 4. Por que isto existe
Projetos de personalização do Windows são alvo frequente de imitações maliciosas. O usuário precisa saber distinguir **o que é oficial e auditável** do que não é. Nome e logo servem a esse propósito: **baixe apenas do repositório oficial e confira o `SHA256SUMS` e a atestação de origem**.

## 5. Nome da Microsoft e "Windows"
"Windows", "Microsoft" e demais nomes são marcas de seus titulares. O BigZ OS **não é afiliado, patrocinado nem endossado pela Microsoft**. Usamos "para Windows 11" apenas de forma referencial (ADR-006).

## 6. Forks e derivados — resumo prático
| Situação | Nome |
|---|---|
| Fork pessoal para estudo | Pode manter o nome do repo; não divulgar como oficial |
| Fork publicado/distribuído com mudanças | **Renomear** |
| Redistribuição **sem mudanças** do release oficial | Pode manter o nome, apontando para o repositório oficial |
| Revenda comercial | Permitida pela GPL **com** código-fonte e créditos; **nome próprio** |
